## 📖 Description

**Scam Marker** plugin for **exteraGram** and **AyuGram** clients.

Marks malicious plugin distributors: red badge in profile, red name in chat list and chat.

Database is automatically loaded from @exteragram_pidors.

---

## 📥 Installation

1. Navigate to the [**Releases**](https://github.com/MaxExteraPlugins/scam_marker/releases/latest) section.
2. Download the `scam_marker_v2.3.0.plugin` file.
3. Send the file to your Telegram Saved Messages or open it via file manager in exteraGram / AyuGram.
4. Tap the file in Telegram and choose **"Install plugin"**.

---

## 📋 Compatibility

* **exteraGram:** `>= 12.10.6`
* **AyuGram:** `>= 12.10.6`
* **Plugin SDK:** `>= 1.4.3.3`
